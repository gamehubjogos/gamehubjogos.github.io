# GameHub asset repository rule

Keep the active contents of every `gamefiles` repository below approximately **4 GiB**. Before adding or moving a large game, calculate the active tree size and use the next mirror when the limit would be exceeded. Keep `asset-host.js`, `games.json`, and the sitemap synchronized with the selected mirror. Expected mirrors: `gamefiles01`, `gamefiles02`, `gamefiles03`, and `gamefiles04`.
